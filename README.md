# Diferència entre IMAP i POP3
• IMAP manté els missatges al servidor i sincronitza tots els canvis en temps real entre el mòbil, la tauleta i l'ordinador.
• POP3 descarrega els correus directament a un sol dispositiu i acostuma a esborrar-los del servidor, alliberant espai al núvol però sense sincronització.
• Ús recomanat: Tria IMAP si revises el compte des de diversos equips, i POP3 només si fas servir un únic ordinador i vols estalviar espai al servidor.
